接口通道

把平台地址、密钥和模型填在这里，保存后画布就能直接用。每个通道下面的 「拉取模型」、「试生成一张图」 和 「试生成一段视频」 都保留。
换电脑时用上面的 「导入 / 导出」：导出会连密钥一起带走，导入后立刻可用。 密钥只保存在这台电脑的配置里，不会写进画布页面。
导出
导入 选文件、或把 JSON 粘 / 拖到下面
「合并导入」：同一个 ID、或者同名但 ID 不同的通道，都用新配置覆盖；其余新增。 换电脑同步时用这个，不会把同一批通道导成两份。
覆盖时保留本机的 ID，画布上已有卡片不会断掉和通道的关联。
改动会自动保存；真正的「试生成」和「拉取模型」会调用对应平台，可能产生费用。
