内置运行时与第三方二进制说明
==============================

以下文件体积较大且不会随开发变动，统一不纳入 Git 版本管理。
克隆仓库后需要按本文件说明单独获取，放回对应位置。

--------------------------------------------------------------------
1. runtime/node.exe
--------------------------------------------------------------------
  版本：Node v24.16.0
  体积：约 89MB
  用途：服务端唯一的运行时依赖

  本项目零第三方 npm 依赖，所有服务端模块均使用 Node 内置模块：
    node:http        手写 HTTP 服务与路由
    node:sqlite      DatabaseSync 做持久化（data/canvas.db）
    node:crypto      ID 生成、哈希
    node:child_process  调用 ffmpeg / ffprobe

  关键版本要求
    Node >= 22.5.0  必须。node:sqlite 的 DatabaseSync 是该版本引入的，
                    低于此版本服务无法启动。

  重新获取
    访问 https://nodejs.org/dist/v24.16.0/
    下载 win-x64 压缩包，将其中的 node.exe 单独复制到 runtime/ 即可。
    无需安装、无需 node_modules。

--------------------------------------------------------------------
2. tools/ffmpeg.exe + tools/ffprobe.exe
--------------------------------------------------------------------
  体积：各约 100MB，合计约 200MB
  用途：
    ffmpeg    生成卡片缩略图（server/thumbs.js，压成 720px webp）
              视频抽首帧、视频转码
    ffprobe   读取视频/音频的时长与分辨率

  重新获取
    访问 https://www.gyan.dev/ffmpeg/builds/ 或 https://ffmpeg.org/download.html
    下载 Windows 静态构建（essentials 版即可），
    将 bin/ 下的 ffmpeg.exe 与 ffprobe.exe 复制到 tools/ 目录。

  验证
    在项目根目录执行：tools/ffmpeg.exe -version
    能输出版本信息即可。

--------------------------------------------------------------------
3. .git-tools/  （便携版 Git，随项目携带）
--------------------------------------------------------------------
  版本：MinGit 2.56.0（git version 2.56.0.windows.4）
  体积：约 92MB / 375 个文件
  位置：.git-tools\cmd\git.exe
  用途：这台电脑上没有任何 git 时的替代品。

  背景：本机原先找不到任何 git，导致 2026-11-04~11-06 的改动一直没能提交，
  四个新子系统（share / codesync / keybox / guard）连一次历史都没有。
  为让「提交」这件事不再依赖环境，把便携版 MinGit 放进项目一起走。

  用法（在项目根目录）
    .git-tools\cmd\git.exe log --oneline
    .git-tools\cmd\git.exe status --short
    .git-tools\cmd\git.exe add -A
    .git-tools\cmd\git.exe commit -m "说明"

  为什么放在根目录的 .git-tools\ 而不是 tools\
    tools\ 在 server/codesync.js 的同步白名单（CODE_DIRS）里，
    放进去会把 92MB 的 git 同步到局域网另一台电脑，
    也会在 git status 里多出 375 个未跟踪文件。
    .git-tools\ 已在 .gitignore 中排除，且经实测
    codesync.isCodeFile('.git-tools/cmd/git.exe') === false。

  重新获取
    访问 https://github.com/git-for-windows/git/releases
    下载 MinGit-x.y.z-64-bit.zip（约 38MB），解压后放成 .git-tools\ 即可。
